# minh anh.ng portfolio
Upload `index.html`, `style.css` and `script.js` to the same folder in your GitHub repository.
Create an `assets` folder and add `cv-svenska.pdf` and `cv-english.pdf`.
Enable GitHub Pages in Settings → Pages. After publishing, hard refresh with Cmd + Shift + R.
Colors are defined in `:root` at the top of `style.css`. Contact email and project copy are in `index.html`; project dialog copy is in `script.js`.
